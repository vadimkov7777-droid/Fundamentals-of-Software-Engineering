# Задачи A1-A3

Тут лежат решения трех базовых задач по программированию (Python).

## Что внутри

*   **A1.py** — Координатная плоскость. Проверяет, лежат ли две точки в одной четверти, и выводит номер четверти. Если в разных — выводит `No`.
*   **A2.py** — Проверка пароля. Смотрит на длину (ровно 8), наличие заглавных/строчных букв, цифр и спецсимволов (`*-#`). Выводит все ошибки, если они есть.
*   **A3.py** — Счетчик газа. Считает разницу показаний (с учетом переполнения после 9999), применяет тарифы по объемам и выводит красивую табличку с суммой и средней ценой за кубометр.

## Запуск

Каждая задача запускается отдельно и ожидает ввод данных с клавиатуры:

```bash
python A1.py
python A2.py
python A3.py
